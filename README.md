# UDC-iN
Computational analysis code for urine-derived cell-induced neurons (UDC-iNs).

## Overview
This repository contains custom computational analysis code used in our study of UDC-iNs for modeling human neuronal aging and neurodegenerative disorders.

## Analyses
- Transcriptomic analysis
- Proteomic analysis
- Statistical analysis and data visualization

Information on the datasets and their accession numbers will be provided upon publication.
