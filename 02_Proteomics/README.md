# Proteomic analyses
This directory contains R scripts used for proteomic analyses in this study. Analysis-specific methods, input data requirements, and instructions are provided in the README files within each subdirectory.

### Code reproducibility
The scripts in this repository have been adapted from the original analysis code used in this study to facilitate broader use and public distribution, while preserving the original analytical procedures and statistical settings. As such, although the original analyses were performed using the source datasets, the scripts have not been rerun in their current, generalized form.
